## 📖 Sobre o projeto

A **Revista Prado Acadêmico** é uma plataforma web desenvolvida com o objetivo de digitalizar, organizar e disponibilizar os trabalhos científicos produzidos pelos estudantes do **Colégio Sinodal Prado**.

O projeto foi desenvolvido em parceria com **Matheus**, desde a estruturação da plataforma até a implementação e organização do conteúdo, buscando criar uma experiência simples, moderna e intuitiva para os leitores.

A plataforma permite que os usuários naveguem pela revista, conheçam os trabalhos desenvolvidos pelos estudantes e tenham acesso aos artigos acadêmicos publicados.

---

## 🎯 Objetivos

O projeto teve como principais objetivos:

- 📚 Disponibilizar os trabalhos acadêmicos em formato digital;
- 📰 Criar uma plataforma própria para a revista;
- 🔎 Facilitar a busca e consulta dos artigos;
- 📄 Permitir o acesso aos trabalhos completos;
- 🖥️ Criar uma interface agradável e intuitiva;
- 📱 Proporcionar uma boa experiência em diferentes dispositivos;
- 🎓 Valorizar e divulgar a produção científica dos estudantes.

---

## ✨ Funcionalidades

- 🏠 Página inicial com apresentação da revista;
- 📚 Catálogo de trabalhos acadêmicos;
- 🔎 Sistema de consulta aos artigos;

## 🤝 Desenvolvimento

Este projeto foi desenvolvido em colaboração com **Matheus**, unindo conhecimentos de desenvolvimento web, design de interfaces e organização de conteúdo.

Durante o desenvolvimento, trabalhamos na criação da estrutura da plataforma, organização das páginas, apresentação dos artigos e construção da experiência de navegação.

## 📚 Conteúdo acadêmico

A revista reúne pesquisas desenvolvidas pelos estudantes em diferentes áreas do conhecimento.

Entre os temas abordados estão:

- 🧠 Desenvolvimento neurológico e consumo de álcool na adolescência;
- 🌊 Impactos das inundações na saúde pública;
- ⏳ Procrastinação e produtividade acadêmica;
- 🎵 Música e crítica social;
- 📱 Tecnologia e qualidade do sono;
- 👨‍👩‍👧 Relações familiares;
- 🎬 Cinema e o gênero de terror;
- 🔬 Outros temas relacionados à pesquisa científica.
